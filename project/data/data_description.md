# Описание данных проекта

## Источник данных

- **Название:** Retail Store Inventory Forecasting Dataset
- **Ссылка:** `https://www.kaggle.com/datasets/anirudhchauhan/retail-store-inventory-forecasting-dataset`
- **Тип:** Синтетические (сгенерированные) данные, обезличенные и не содержащие конфиденциальной информации.
- **Лицензия:** Открытая (доступны для свободного использования в учебных и исследовательских целях).

## Структура исходного датасета

Датасет находится по пути `./data/retail_store_inventory.csv` и содержит 73 100 записей о ежедневных продажах магазина со следующими колонками:

| Поле                | Тип       | Описание                                                                 |
|---------------------|-----------|--------------------------------------------------------------------------|
| `Date`              | дата      | Дата записи (формат DD.MM.YYYY)                                          |
| `Store ID`          | строка    | Уникальный идентификатор магазина (S001, S002, …)                        |
| `Product ID`        | строка    | Уникальный идентификатор товара (P0001, P0002, …)                       |
| `Category`          | строка    | Категория товара (Groceries, Toys, Electronics, Clothing, Furniture)     |
| `Region`            | строка    | Регион магазина (North, South, East, West)                               |
| `Inventory Level`   | целое     | Текущий уровень запасов                                                  |
| `Units Sold`        | целое     | **Целевая переменная** - количество проданных единиц                     |
| `Units Ordered`     | целое     | Количество заказанных единиц                             |
| `Demand Forecast`   | вещественное | Прогноз спроса                                     |
| `Price`             | вещественное | Цена товара                                                              |
| `Discount`          | целое     | Скидка в процентах                                                       |
| `Weather Condition` | строка    | Погода (Rainy, Sunny, Cloudy, Snowy)                                     |
| `Holiday/Promotion` | целое (0/1) | Признак праздника или промо-акции                                        |
| `Competitor Pricing`| вещественное | Цена конкурента                                                          |
| `Seasonality`       | строка    | Сезон (Spring, Summer, Autumn, Winter)                                   |

## Агрегация для задачи прогнозирования

Для построения модели прогноза общего объёма продаж данные были агрегированы по дате и категориям и записаны в соответсвующие файлы:

- `./data/processed/Clothing_series.csv` - данные о ежедневных объёмах продаж одежды
- `./data/processed/Electronics_series.csv` - данные о ежедневных объёмах продаж электроники
- `./data/processed/Furniture_series.csv` - данные о ежедневных объёмах продаж мебели
- `./data/processed/Groceries_series.csv` - данные о ежедневных объёмах продаж продуктов
- `./data/processed/Toys_series.csv` - данные о ежедневных объёмах продаж игрушек
